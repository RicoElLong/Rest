Проект для согласования. Контакт для обращений и сроки хранения данных уточняются до утверждения документа.

Оператор персональных данных

ООО «Дети Лейтенанта Шмидта» (ИНН 6316182140).

На что распространяется политика

Политика описывает обработку данных посетителей сайта ресторана «Дети лейтенанта Шмидта» и гостей, которые связываются с рестораном через каналы, указанные на сайте.

Для чего используются данные

Работа сайта
При просмотре страниц браузер передаёт технические данные, необходимые для загрузки, в том числе IP-адрес. Версия сайта на GitHub Pages использует хостинг GitHub, который регистрирует IP-адреса посетителей для обеспечения безопасности. Для загрузки шрифтов и отдельных изображений главная страница может обращаться к Google Fonts и Unsplash.
Бронирование по телефону
Гость может сообщить имя, телефон, желаемую дату и время визита, число гостей и пожелания. Ресторан использует эти сведения, чтобы обработать запрос, связаться с гостем и согласовать детали бронирования.
Заявка через форму на сайте, если она включена
Ресторан получает имя, телефон, желаемые дату и время, число гостей и комментарий, если гость его добавил. Сотрудник связывается с гостем, уточняет детали и сообщает результат рассмотрения заявки.
Обратная связь в Telegram после запуска
Для рассмотрения вопроса, отзыва или предложения используются идентификатор чата и содержание обращения. Гость может сообщить имя или контакт для ответа. Сведения используются для обработки обращения и ответа на него.
Регистрация в боте после запуска
Для регистрации могут использоваться идентификатор пользователя Telegram, имя, номер телефона и запись о согласии. Дата рождения предоставляется по желанию для персонального предложения. Этот сценарий предполагает отдельное согласие на обработку данных.

При переходе в Яндекс Карты, Яндекс Еду или Telegram обработка данных на стороне сервиса регулируется его документами. Данные, которые гость передаёт ресторану через эти сервисы, ресторан обрабатывает для соответствующего запроса.

Основания и порядок обработки

В зависимости от цели основанием обработки служат согласие гостя, действия по его запросу для заключения или исполнения договора либо исполнение обязанности, установленной законом.

Обработка может включать получение, запись, хранение, уточнение, использование и удаление данных. Доступ предоставляется сотрудникам, которые обрабатывают бронь или обращение. По достижении цели обработки данные подлежат удалению или обезличиванию с учётом сроков, установленных законодательством.

Права гостя

Гость вправе запросить сведения об обработке своих данных, потребовать их уточнения, блокирования или удаления при наличии оснований, а также отозвать согласие. Действия оператора можно обжаловать в Роскомнадзоре или в суде.
