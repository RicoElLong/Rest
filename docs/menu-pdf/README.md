# PDF-меню: пять вариантов

Каждый PDF содержит 48 блюд в 10 категориях, 12–20 страниц A4, текст с внедрёнными кириллическими шрифтами. Цены взяты из assets/menu.json и остаются предварительными. Все weightGrams в исходнике пустые: колонка «Выход» содержит «—», без выдуманных порций. Для напитка при получении данных следует использовать мл, не г.

1. 01-classic.pdf — Волжская классика: тёмное меню с тонкой латунной рамкой.
2. 02-compact.pdf — Кабинет ресторатора: три колонки, до 6 блюд на странице.
3. 03-photographic.pdf — Гастрономический альбом: крупное фото каждого блюда рядом с текстом.
4. 04-print.pdf — Латунь и бумага: светлая версия для печати.
5. 05-art-deco.pdf — Вечер на Волге: геометрическая рамка и орнамент.

Для обновления: python3 docs/menu-pdf/generate.py (ReportLab, Pillow, PyMuPDF и DejaVu TTF). Макеты для согласования: не подключены как основное меню сайта.

Каждому блюду соответствует отдельная временная фотоиллюстрация из сайта: по 48 фото во всех пяти PDF. Генератор проверяет количество фото и наличие всех названий. Изображения сжаты в JPEG для загрузки с сайта. Референс https://milimon-family.ru/assets/files/menu/fire/fire_mainmenu.pdf недоступен из среды (HTTP 403), поэтому точное соответствие его композиции не проверялось.

Обновлённая композиция: фото заполняет всю карточку блюда. Название, выход и цена расположены поверх фото; под ними прозрачный чёрно-зелёный градиент. Никаких отдельных подписей под фотографиями или сбоку.
