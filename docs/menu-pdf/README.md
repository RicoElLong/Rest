# PDF-меню: пять вариантов

Каждый PDF содержит 48 блюд в 10 категориях, 4 страницы A4, текст с внедрёнными кириллическими шрифтами. Цены взяты из assets/menu.json и остаются предварительными. Все weightGrams в исходнике пустые: колонка «Выход» содержит «—», без выдуманных порций. Для напитка при получении данных следует использовать мл, не г.

1. 01-classic.pdf — Волжская классика: тёмное меню с тонкой латунной рамкой.
2. 02-compact.pdf — Кабинет ресторатора: двухколоночная вёрстка.
3. 03-photographic.pdf — Гастрономический альбом: фото-заставки, временные иллюстрации из сайта.
4. 04-print.pdf — Латунь и бумага: светлая версия для печати.
5. 05-art-deco.pdf — Вечер на Волге: геометрическая рамка и орнамент.

Для обновления: python3 docs/menu-pdf/generate.py (ReportLab, Pillow, PyMuPDF и DejaVu TTF). Макеты для согласования: не подключены как основное меню сайта.
